# Pharma Battle

Multiplayer Node.js + WebSocket quiz. 10 questions per game: easy=1, medium=3, hard=5. Each question has 10 seconds.

Run locally:
```bash
npm install
npm start
```
Then open http://localhost:3000 on the host and other phones on the same network using the host's LAN IP.

For a permanent public URL, deploy this Node/WebSocket project to a host that supports long-running Node.js WebSocket apps.
